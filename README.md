# Random Dota Build

Генератор рандомного героя и рандомного билда из 6 предметов для Dota 2.
Без попыток сделать его "умнее" — если первым выпал Divine Rapier, играешь
через Rapier. Если Swift Blink — копи 6800 золота и страдай. В этом и суть.

<pre style="white-space: pre-wrap;">
1. Divine Rapier
2. Butterfly
3. Pipe of Insight
4. Dagon 5
5. Arcane Blink
6. Satanic
</pre>

Порядок, в котором выпали предметы — это и есть порядок покупки. Никакой
дополнительной логики поверх.

# Как это работает

Все герои и предметы берутся не из головы, а из открытого репозитория
[odota/dotaconstants](https://github.com/odota/dotaconstants) — на нём же
держится OpenDota. Предметы прогнаны через фильтр: без расходников,
рецептов, стартовых статовых вещей и прочего мусора — остаются только
полноценные "финальные" предметы.

Из предметов с несколькими уровнями (Dagon, Necronomicon, Diffusal Blade)
в ротации только максимальный уровень — чтобы не выпадал недостроенный
Dagon 1 вместо Dagon 5.

# Требования и запуск

Зависимостей нет вообще. Никакого `npm install`, никакого сервера.

```
Скачал / склонировал → открыл index.html в браузере → готово
```

Если хочешь скинуть другу один файл без танцев с папками — используй
`standalone.html`, там всё (стили, скрипты, данные героев и предметов)
склеено в одну страницу.

## Клонируем

```bash
git clone https://github.com/ТВОЙ_НИК/dota-random-build.git
cd dota-random-build/
```

## Запуск

```
просто открой index.html двойным кликом
```

# Как пользоваться

1. **🎲 Новый герой** — рероллит только героя, билд остаётся.
2. **🎲 Новый билд** — рероллит только билд, герой остаётся.
3. **🎲 Всё сразу** — новый герой + новый билд.
4. **⟳ на предмете** — реролл одного конкретного слота. Полезно, если
   предмет уже выпилили из игры патчем, а данные ещё не обновились.
5. **Weirdness** — выключает запрет на повторы. Может выпасть 3 Parasma
   подряд. Без этого тумблера: без дублей, не больше 1 blink и 1 пары
   ботинок.
6. **Difficulty** — показывает Challenge Score (1-5 звёзд) — насколько
   дикий получился билд.

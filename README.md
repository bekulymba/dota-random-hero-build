# Random Dota Build

Генератор рандомного героя и рандомного билда из 6 предметов для Dota 2.

<pre style="white-space: pre-wrap;">
1. Divine Rapier
2. Butterfly
3. Pipe of Insight
4. Dagon 5
5. Arcane Blink
6. Satanic
</pre>

Порядок, в котором выпали предметы — это и есть порядок покупки.

# Как это работает

Все герои и предметы берутся из открытого репозитория
[odota/dotaconstants](https://github.com/odota/dotaconstants) - на нём же
держится OpenDota. Предметы прогнаны через фильтр: без расходников,
рецептов, стартовых статовых вещей и прочего мусора — остаются только
полноценные "финальные" предметы.

# Ограничения
1. По умолчанию в билде может быть только 1 блинк и 1 ботинок (Режим Weirdness - отключает это правило).
2. Предметы не повторяются (Режим Weirdness - отключает это правило).
3. Минимальная сумма айтемов - 800 золота, чтобы избежать **bracer**, **null talisman**, **bottle** и т.д.
4. Отключены следующие айтемы: **Aghanim's Shard**, **Oblivion Staff**, **Perseverance**, **Soul Booster**.


# Геймплей
Играйте как хотите.
Не можете решить? Вот на выбор несколько вариантов

## Classic
1. Айтемы до 800 и расходники могут быть купленны в любой момент. Очередность сборки остается заданная порядком покупки.
2. Если в айтеме не указана финальная версия, к примеру Diffusal Blade, после завершения билда можно докупить Disperser.

## Chill
1. Айтемы закупаются в свободном порядке, то есть можно собрать первым айтемом - 6 слот в сборке и т.д.
2. Даже если не доделал айтем, можно переключиться на другой.

## Low Priority
1. Айтемы закупаются строго с порядком заданным в сборке (запрет на расходники).
2. Если в айтеме не указана финальная версия - нельзя апать. К примеру Diffusal Blade - он останется Diffusal Blade до конца игры.

# Как пользоваться

1. **🎲 Новый герой** — рероллит только героя, билд остаётся.
2. **🎲 Новый билд** — рероллит только билд, герой остаётся.
3. **🎲 Всё сразу** — новый герой + новый билд.
4. **⟳ на предмете** — реролл одного конкретного слота. Полезно, если
   предмет уже выпилили из игры патчем, а данные ещё не обновились.
5. **Weirdness** — выключает запрет на повторы. Может выпасть 3 Parasma
   подряд. Без этого тумблера: без дублей, не больше 1 blink и 1 пары
   ботинок.
6. **Difficulty** — показывает Challenge Score (1-5 звёзд) — насколько
   дикий получился билд. // needs rework
